# Individual bias-attribute plots

Each dataset subdirectory contains one four-panel PDF and PNG for each of its
three bias attributes. The panels show Uniform time, Uniform expected utility,
Gaussian time, and Gaussian expected utility as the number of intent
attributes increases.

These figures disaggregate the existing distinct-bias experiment: each bias
attribute was run separately with five bias realizations and four bias
strengths. They are not results for a joint multi-attribute bias variable.

`index.csv` lists every figure and its human-readable bias-attribute label.
